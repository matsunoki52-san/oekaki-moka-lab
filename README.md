# ぬりえ あそび (oekaki)

3歳の幼児がiPadで直感的に遊べる、はみ出さない高機能塗り絵Webアプリ（PWA）。

## 特長

- **はみ出し防止ロジック（クリッピングマスク）**
  - 背面 `<canvas>` と前面 `<svg>` の2層構造。
  - タッチ開始時（`pointerdown`）に触れた `<path>` のパスデータから `Path2D` を生成し、`ctx.save()` → `ctx.clip()` を適用。
  - 手前に重なる部位は `evenodd` 合成でくり抜き除外するため、重なり順も自然に保持。
  - なぞり中（`pointermove`）に指が別の部位へ動いても、最初にタッチした部位の内側だけに描画が限定されます。
  - タッチ終了時（`pointerup`）に `ctx.restore()` で解除。
- **5種類の楽しい描画ツール**
  - **ペン**: 単色およびグラデーション「にじいろ」ペン。
  - **もよう**: 20種類のシームレスパターン（水玉、ストライプ、チェック、ハート、星、ギンガムなど）。
  - **キラキラ**: 星型・ハイライト粒子のパーティクル生成ペン（`requestAnimationFrame`）。
  - **スプレー**: 密度グラデーションを持つエアブラシ風スプレー。
  - **けしゴム**: `destination-out` により前面の主線SVGを傷つけずCanvasの塗りだけを消去。
  - **ぜんぶけす**: 3歳児でも押し間違いを防ぐ大きな○×確認モーダル付き。
- **大容量パレット**
  - 25色の厳選カラー（にじいろ含む）と20種のもようパレットを横スライドで選択可能。
- **4ジャンル・12種類のベクター台紙**
  - どうぶつ（ねこ・いぬ・さかな）
  - のりもの（くるま・でんしゃ・ロケット）
  - キャラクター（ロボット・おばけ・おほしさま）
  - たべもの（アイス・ケーキ・くだもの）
- **iPad / PWA 最適化**
  - `manifest.webmanifest` / Service Worker 完備でオフライン動作・ホーム画面追加に対応。
  - `touch-action: none` および各種イベント制御によるピンチズーム・予期せぬスクロール・長押し選択の完全抑止。
  - WebAudio による心地よいポップ音・効果音（外部音声ファイル不要）。
  - IndexedDB による自動保存（途中まで塗った絵の台紙サムネイルプレビュー対応）。
  - Web Share API 連携による「画像を保存」および PNG ダウンロード対応。

## 開発・ビルド

### 動作環境
- Node.js 18+ (推奨 LTS)

### インストールと起動
```bash
npm install
npm run dev
```

### ビルド
```bash
npm run build
```
